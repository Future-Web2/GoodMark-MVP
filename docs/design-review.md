# Goodmark — локальный черновик дизайна

Подготовлен для просмотра 8 октября 2026 года. Изменения не отправлены в GitHub и не опубликованы на текущем сайте.

## Что изменено

- Главная: более крупная типографика, композиция с иллюстрацией устройства и отдельным блоком помощника.
- Каталог: фильтры слева на широком экране, раскрывающаяся панель на телефоне, более читаемые карточки с датой прайса.
- Быстрые переходы по реальным брендам и категориям; поиск работает по всему каталогу.
- Новые SVG-иллюстрации устройств без выдуманных логотипов моделей.
- Карточки доступны с клавиатуры, кнопка избранного отделена от открытия товара.

Товары, цены и ссылки на источники сохранены. Фото по-прежнему заменены подписанными иллюстрациями. Помощник в автономном превью работает в сценарном режиме.

## Просмотр и запуск

Goodmark-design-preview.html — один файл для просмотра дизайна в браузере. Для полного запуска проекта: откройте папку outputs/GoodMark-MVP-GitHub, выполните npm start и перейдите на http://127.0.0.1:4173/.

В исходниках изменения оставлены локально. Решение о публикации и загрузке в репозиторий принимается после просмотра дизайна.
