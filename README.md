# Goodmark — каталог по реальному Telegram-прайсу

В каталоге 49 позиций восьми брендов из публикаций Goodmark за 18–25 сентября 2026 года. Источники проверены 7 октября 2026 года. Это опубликованные цены в у.е.; их актуальность на день покупки и наличие подтверждает менеджер. Иллюстрации временные, реальные фотографии добавляются позже.

## Рабочие функции

- Каталог с поиском RU/UZ, фильтрами категории, бренда, типа товара, подключения и цены, сортировкой, избранным и карточками со ссылками на источник и датой цены.
- Корзина с количеством 1–20, итогом в у.е. и черновиком заявки. Пользователь может скопировать или скачать текст и открыть Telegram. Сайт сам не отправляет сообщения магазину.
- Сценарный помощник подбирает существующие позиции и добавляет согласованный комплект в корзину. Для Lexar RAM/SSD актуальных подтверждённых цен нет: помощник сообщает об отсутствии данных, без выдуманных товаров.
- Сохранение UTM-меток, ссылки на отфильтрованный каталог и товары, конструктор рекламных ссылок с обязательным utm_source.
- Локальная панель просмотров, действий с корзиной, черновиков и источников. Она показывает события этого браузера; подтверждённые покупки, выручка и общая статистика посетителей требуют серверной интеграции.
- Импорт и экспорт CSV с ценами, датами и источниками. Импорт меняет каталог только в текущем браузере. Шаблон: dist/catalog-template.csv.

## Запуск и проверка

Нужен Node.js 22+. Команды: `npm run build`, `npm start`, `npm test`. Локальный адрес V2: http://127.0.0.1:4173. Зависимостей npm нет.

32 теста проверяют реальный каталог, фильтры, цены и суммы, количества, черновик заявки, UTM, CSV, сценарный подбор, ограничения действий AI, маршруты и целостность всех страниц. Проверены переходы в браузере, перезагрузка, возврат назад и мобильная раскладка.

## Две версии и GitHub Pages

Главная страница публикации — выбор V1 или V2. V1 сохраняет первый одностраничный MVP из коммита `a651d2e` (снимок в `versions/v1`). V2 — новый дизайн и 12 HTML-страниц: главная, каталог, мыши, клавиатуры, звук, товар, корзина, избранное, помощник, Telegram-демо, бизнес-панель и контакты.

`npm run build:pages` собирает папку `site`: `index.html` с выбором версий, `v1/` и `v2/`. Для локального просмотра обеих версий выполните `npm run preview:pages` и откройте http://127.0.0.1:4174. На страницах V2 ссылка «Выбор V1 / V2» находится внизу сайта. Переходы сохраняют UTM, корзину и избранное. История подбора хранится в текущей вкладке.

Workflow `.github/workflows/pages.yml` публикует `site` через GitHub Actions при обновлении `main`. В Settings → Pages источник должен быть GitHub Actions. На GitHub Free репозиторий для Pages должен быть публичным; для приватного нужен подходящий платный тариф. Ожидаемый адрес после успешной публикации: https://future-web2.github.io/GoodMark-MVP/.

GitHub Pages размещает статическую витрину. Сценарный помощник работает; Node API и настоящий Telegram-бот требуют отдельного сервера. Панель аналитики отражает действия только текущего браузера, а подготовленные сообщения не являются подтверждёнными продажами.

## Следующее подключение

ai-service.mjs содержит интеграцию с моделью через серверный API; для живого AI нужны ключ и размещение Node-сервера. Опубликованная статическая витрина работает со сценарным помощником. Ключи нельзя размещать в браузере.

telegram-bot.mjs содержит код бота; для запуска нужны TELEGRAM_BOT_TOKEN, SITE_URL и постоянно работающий сервер. Реальный бот пока не зарегистрирован и не запущен. Оплата, резервирование остатков, доставка, авторизация сотрудников и общая серверная аналитика требуют согласования и подключения магазина.

## Переменные окружения

Пример имён переменных: .env.example. Сервер читает окружение процесса. Для локального запуска с файлом используйте `node --env-file=.env server.mjs`, для бота — `node --env-file=.env telegram-bot.mjs`. Без ключа AI сайт использует сценарный подбор. SITE_URL для бота должен быть доступен его пользователям по HTTPS.

Текущий MVP: https://goodmark-market-mvp.gitdevweb.chatgpt.site — доступ ограничен аккаунтом владельца. Код из этого репозитория можно развернуть отдельно. Настройки существующего хостинга в репозиторий не включены.
